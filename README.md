 #  Vertex academy
 ### Site de Idiomas

 #  Projeto da Vertex academy
 #####  A Vertex Academy tem como projeto , transformar a maneira como você se conecta com o mundo. Unimos metodologias com  dinãmicas trazendo praticidade na hora de aprender facilitando a conversação e aprendizagem Nosso site de idiomas foi desenvolvido para oferecer uma experiência completa e personalizada no aprendizado de Francês, Inglês e Espanhol. Cada projeto foi pensado para atender diferentes perfis de alunos, desde iniciantes até avançados, com foco na prática e na imersão cultural.
#  Nosso Objetivo 
#####  A Vertex academy tem como principal objetivo tornar o aprendizado de Francês, Inglês e Espanhol acessível, prático e motivador . Queremos ir além das aulas tradicionais, oferecendo uma plataforma que une tecnologia, interatividade e imersão cultural para que cada aluno aprenda de forma natural e confiante.

Buscamos criar um ambiente virtual onde o estudante possa:

+ Aprender no seu próprio ritmo, com conteúdos organizados por níveis e objetivos.
+ Praticar de forma constante, por meio de exercícios, conversações e desafios semanais.
+ Conectar-se com a cultura de cada idioma, explorando costumes, expressões e curiosidades.
+ Acompanhar seu progresso e celebrar cada conquista com certificações digitais.

#  Publico-alvo
##### Trouxemos um site versatil e pratico para conserguimos atingir um publico para pessoas de diferentes idades e necessidades.A intençâo e fazer que todos consiga ter acesso sem restrição de idade  

# Tecnologias Utilizadas 
+ Usamos HTML5 para fazer a estrutura do site da vertex academy
+ Usamos CSS3 para estilizar o tamanhos da imagens, cores e fontes dos textos
+ Usamos BOOSTRAP para criar carrosel cards e botões

# Estruta do site 
+ HEADER O nome do site de Idiomas
+ NAV conteudo do cabeçalho
+ SECTION Conteudo do site
+ SECTION DIV CARD valores das mensalidades e cursos disponiveis
+ SECTION DIV CARROSEL Imagens dos cursos disponiveis
+ CONTATO\RODAPÉ Contato e inforamções finais

# Responsividade
##### O site da vertex academy Utilizou recursos com codigos prontos do Boostrap para adaptar o conteudo para diferentes tamanhos de tela como celular notebook ou tablet.

# Acessibilidade 
+ Os Titulos seguem uma ordem do conteudo do site
+ As imagens possuem legendas usando o ALT
+ os cards estão numerados conforme os cursos ofertados

# Decisões de UX
##### Pensando no facil acesso para todos no conteudo do site decidimos manter alguns padrôes
+ Manter o menu\cabeçalho com questionamentos chaves faceis de entender
+ Separamos o conteudo em seçôes
+ Deixamos os valores anual e mensal bem explicativo
+ frizamos uma linguagem de facil entendimento
